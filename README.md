# ebook-reader

自包含、高性能、中文排版考究的桌面 EPUB 阅读器。

**不使用** Chromium / WebKit / Electron / GTK。排版由 Qt 自身的富文本引擎完成，
运行时依赖只有 **1 个**：`PySide6-Essentials`。

## 为什么值得做

| | 本阅读器 | Calibre / Electron | Foliate / Tauri |
|---|---|---|---|
| 排版引擎 | Qt `QTextDocument`（自带 CJK 字间对齐） | Chromium | 系统 WebKitGTK |
| 运行时依赖 | **1 个 Python 包** | 捆绑 Chromium | 绑定系统 webkit2gtk |
| 滚动发行版升级后 | 不受影响 | 不受影响 | **可能直接打不开** |
| 内存 | ~150 MB | 350–450 MB | ~400 MB |
| 避头尾（禁则） | **实测 645 行 0 违规** | 依赖 CSS，通常不做 | 依赖 CSS |

## 特性

- EPUB 2 与 EPUB 3（含无扩展名文档、脏 HTML、内联样式）
- 中文两端对齐、首行缩进、可调行距 / 字号 / 边距
- **避头尾**：通过注入 U+2060 WORD JOINER 在字符流层面强制禁则，与 Qt 版本无关
- 图片按需解码（408 张图 / 85 MB 的书只占 ~27 MB 图片缓存）
- **连续滚动**：一节 = 一条连续列，没有页边界；图片不被列挤扁或拉伸，标题与其正文不分离
- 日间 / 米色 / 夜间三主题，宋体 / 黑体 / 楷体三字体；三主题同一套三层表面——**纸 > 带 > 面板**
  （纸是正文栏，面板是目录栏 / 大纲栏 / 菜单 / 状态栏，「带」是画在纸上的那两条条带，见下）
- **三栏布局**：目录 ｜ 正文 ｜ 本节大纲，三栏同时可见，正文按剩余宽度重新排版
  - 大纲列出本节自己的标题（h1–h3）；本节没有标题时该栏不出现（连续列没有「页」，因此没有按页回退这一说）
  - 打开书时目录栏**自动展开**（书没有目录则不占栏），关书后两栏一起收起
  - 目录栏**常驻**：点目录项跳转、滚动正文、按 `S` 调字号都不会把它收起；**状态栏左下角常驻「目录」按钮**
    （开栏时填充主题色、关栏时描边，右端标出快捷键 `T`），单击即可显示 / 隐藏，无书时置灰
  - 目录栏**滚到哪就停在哪**：点目录项、`]` 换章都不会把列表弹回第一行（缺陷 25），只有重新打开栏才按读者的
    位置居中；当前章节以**左侧强调色竖条**标出，子层缩进 16 px 并画祖先引导线，栏头两行（「目录」+ 书名）
- **鼠标拖拽平移正文**（FR-079）：在正文上按住左键拖动，文字跟着指针走（与地图、触屏同一方向）；
  位移按「按下点到当前点」算，所以拖到节首再往回拖时文字立刻跟着回来，不必先「还清」越界的距离
- **文本选择与复制**（FR-070）：按住 `Shift` 左键划过一段，**松手即进剪贴板**并在状态栏报「已复制 N 字」；
  `Shift` 单击或双击取指针下的**一个词**（中文取指针所在的分句，而不是整段）；`Ctrl+C` 把标出的那段重新放回剪贴板，
  在正文上单击即放下高亮（剪贴板不受影响）。高亮画在那张位图之上，所以滚动时始终贴着自己那一行
- **鼠标右键菜单**：窗口内任意位置右键即可展开全部操作（打开文件、目录 / 大纲 / 设置、复制、滚动与章节跳转、
  字号 / 行距 / 边距 / 字体 / 对齐 / 主题、关闭面板、全屏、退出），每行右侧标出对应快捷键，当前状态带勾选
- 目录侧栏、**本卷 / 全书位置百分比**（不显示页码）、阅读位置记忆（跨字号、跨窗口尺寸都有效）
- 目录项落在它指向的地方：`href` 解析到节、`#frag` 解析到块（EPUB2 常见的空 `<a id>` 标记、`<div id>` 包住段落的写法都算），
  同一文件里的多章各就各位；左栏高亮按**位置**判定，所以「同一文件里的第二个目录项」也能被标记
- **目录列出书没点名的那些节**（FR-012）：发布者写在 `nav` / `toc.ncx` 里的条目照用，没被点名的节按**阅读顺序**补行，
  用**该节自己的首行**命名（标记为标题的行直接用，否则要求短、且无句读，于是图注与纯图封面不成行）。合集参考书
  的 NCX 只有 3 条卷级条目，左栏因此是 **134 行**而不是 3 行，点任一行都落到那一节
- **点开目录行就读到那一章**（FR-016 / ADR-021）：转换书常把每一章切成「章名图 + 正文」两个文档，而目录只指向那张图。
  本阅读器把这种**通篇只有图片的扉页**与其后「书没点名、自己也说不出名字」的文档并成**一节**：点开一行，往下滚就是
  这一章的正文，滚到底出现的才是**下一章**；能被点名的文档仍各自成行，所以**目录行数一行不变**（缺陷 27）
- **打开书时窗口自动最大化**（FR-077）：命令行开书与运行中 `Ctrl+O` 换书都生效；不带书启动的空壳窗口仍是默认尺寸，
  `F11` 的全屏沉浸模式优先
- **左栏宽度可用鼠标拖动**（FR-078）：把鼠标移到目录栏右缘（光标变成 ⇔）按住拖动即可**加宽或收窄**，宽度限制在
  160–480 px，且正文栏始终不少于 320 px；**松开鼠标即记住**，下次启动就按这个宽度打开；双击分割条恢复自动宽度

## 安装与运行

```bash
python3 -m venv .venv
.venv/bin/pip install PySide6-Essentials      # 唯一运行时依赖

# 运行（源码直接跑）
PYTHONPATH=src .venv/bin/python -m ebook_reader 你的书.epub
```

## 快捷键

| 键 | 作用 |
|---|---|
| `↑` `↓` | 滚动一行 |
| `←` `→` / `PgUp` `PgDn` / `空格` / `Backspace` | 滚动一屏（视口高 − 一行） |
| `Home` / `End` | 本节列首 / 列尾 |
| `[` / `]` | 上一章 / 下一章 |
| `T` / `O` / `S` | 目录 / 本节大纲 / 设置 |
| `Ctrl` `+` / `-` | 字号 |
| `Ctrl+C` | 把标出的那一段重新放进剪贴板 |
| `F11` | 全屏 |
| `Esc` | 关闭所有面板 |
| `Ctrl+O` / `Ctrl+Q` | 打开文件 / 退出 |

滚轮一格滚 3 行（与键盘同一套行高，事件被接受、不再冒泡）；鼠标滚轮发的是 `angleDelta`（120 单位 = 一格），
触控板与平滑 / 自由滚动的滚轮**只发 `pixelDelta`**，于是按像素原样位移——两种形态分开处理，无论哪一台机器都滚得动。
处理滚轮的那个 QML 处理器还**同时接受鼠标与触摸板设备**：Wayland 上 Qt 把每个滚轮事件都记在座位的指针设备名下，
而该设备登记为「触摸板」，只收鼠标的处理器会在 `onWheel` 之前就把事件拒掉（缺陷 24）。
**点击正文不会移动文字**——连续滚动里「半页」「一页」都是猜出来的单位，所以移动文字的是键盘、滚轮、滚动条与**按住左键拖拽**（滚动条可点击 / 拖动跳转）。
按住左键拖动即抓住这一列：文字跟着指针走（指针下移 = 退回上文），松手停在松手处；位移按「按下点到当前点」算而**不是累加每次移动的增量**，
否则拖到节首再往回拖时，读者得先把手走回去文字才肯动。按住 `Shift` 拖动则是**标记**：从按下那个字到松手那个字，
松手即复制进剪贴板并在状态栏报字数；`Shift` 单击与双击取**一个词**（西文按 Qt 的词，中文按指针所在的**分句**——
Qt 自己的「词」在中文里是到下一个空白为止的整段），单击正文则放下已经标出的高亮。两种手势由按下时的修饰键区分，
不设模式、不用长按计时，因此拖动途中松开 `Shift` 也不会让手势改变含义。
正文栏顶部**常驻一条位置栏**，写着读者所在正文的**层次与名字**——取目录高亮的那一行，
按目录树由外到内排列（如「第一部分 涛动周期论 › 01 人生财富靠康波——康波中的价格波动」），
最外层用弱色、当前那一层用正文的墨色加粗、背景用**纸退一档的「带」色**（比页面深、比目录栏那种面板浅，
与章末那条同色，因此正文栏不会被看成「第四栏」）；它贴着栏顶、**不随文字移动**
（窗口位图从它下面滑过），占的是正文栏的上边距。它**不是按钮**——回上一章用 `[`、菜单或目录栏。
章末仍出现一行「下一章 · 〈标题〉」，**居中**于正文栏、底色就是那条「带」，点它即换到那一章（等效 `]`，从列尾回退落在上一章列尾，
那里又写着「下一章」，一次点击就能回来）；**它绝不会自动带读者离开本章**，离开列尾后那一行也随之消失。
**鼠标右键在窗口任意位置弹出「全部操作」菜单**（22 行，含勾选状态与快捷键提示，右侧 6 行是字号 / 行距 /
边距 / 字体 / 对齐 / 主题的子菜单）；**状态栏左下角常驻「目录」按钮**，单击即显示 / 隐藏左栏
（开关态一眼可见，并标出快捷键 `T`）；目录与大纲占正文两侧的独立栏位（点击栏内条目跳转，都不自动收起，
便于连续跳转）；设置面板是浮层抽屉，它只让出右侧的大纲栏，不会带走左侧目录。

两本书都以「一节一列」呈现：越过节端**不会**自动滚进下一章（拼接两文档要做偏移换算、跨文档图片预取与
位置记忆，v1 有意不做），换节由 `]` / `[` / 菜单 / 节末那一行显式触发。
**目录栏的右缘是一条可以拖的分割条**（光标变成 ⇔ 时按住拖动）：往右拖加宽、往左拖收窄；两条栏同宽
（它们是同一张地图的两半，所以大纲栏也跟着一起变），松手后这次的宽度就写进配置，下次打开还是它；
拖动范围限制在 160–480 px，且正文栏始终不少于 320 px（拖到窗口边缘就停），双击分割条交回给窗口自己算。

所以集成套件里每项都在**最大化后的窗口**上跑（离屏屏幕 800×800），需要特定尺寸的用例用

## 已知限制（有意为之）

- 不支持 **竖排（直排）** 与 **ruby 注音**：Qt 6 无此能力，自研成本为年级
- 不支持表格：实测两本目标书均为 0 个 `<table>`
- 相邻两节**不拼接**成一条流（一节 = 一列）：跨章靠 `]` / `[` / 菜单 / 节末提示，不做自动衔接
- 章的边界由**目录行**与「这一页有没有字」决定，而非由文档边界：目录行指向**纯图片扉页**时，其后「书没点名、自己也说不出名字」
  的文档并进同一节（点开一行即可读到整章）；但一条行指向**能自报家门**的文档时**不并**——合并会拿走那一章自己的行
  （实测：合集参考书会从 135 节 / 134 行变成 4 节 / 131 行），而「能看见每一节」正是这张地图存在的理由（FR-016 / ADR-021）
- 没有页码（连续列没有页），进度以「本卷 x% · 全书 y%」表示，其中全书百分比是估算
- 仅 EPUB，不支持 PDF / MOBI / AZW3
- 目录解析**不要求文档合法**：`nav` 缺 `<ol>`、平铺的 `<a>`、不闭合的 `navPoint`、文档自己声明了非 UTF-8 编码
  （`<?xml … encoding="gbk"?>`）都能读出条目，也不再让 `ValueError` 冒成回溯（容错读取器 + 尊重文档声明的编码，见
  `arch/architecture.md` 缺陷 18、23）；书**自己声明**的结构一律照办 —— `<base href>` 换基准、`spine@toc` 指到
  `toc.ncx`、`linear="no"` 的文档被「上一章 / 下一章」按规范跨过（缺陷 19–21）；`landmarks`（FR-009）只认自己声明
  `epub:type="landmarks"` 的那个 `<nav>`，书没写就没有，不拿目录页凑数
- 目录只读书里**写明的结构**（先 `nav.xhtml`，再 `toc.ncx`）**与每节自己说的第一句话**：书没点名的节用**该节自己的首行**命名
  （标记为 `h1`–`h6` 的标题直接用；否则要求短、且无句读，因此图注与纯图封面不成行）。
  **不从正文的「目录页」或排版字号反推目录树**：合集参考书的目录页虽然自己用 `<a href>` 连到了每一章，
  这些链接也不采信——逐节命名已经覆盖了它们，而且不会把正文里的普通链接误当目录。于是那本书的左栏是 **134 行而不是 3 行**，
  点任一行都落到那一节；一条目录条目都没有的书同样逐节命名（FR-012）
- 书写了目录、却**只画一层**的书，层级从**每节自己写的标题**还原：EPUB 3 参考书的 `nav.xhtml` 是 26 个并列的 `<li>`，
  于是三个「第 N 部分」与 18 章按正文的 `<h1>` / `<h2>` 分出上下层，左栏画出的是树而不是一列 26 行。
  比的是**相对深浅**（最浅的标题即顶层，整本用 `<h2>` 的书不会整体缩进），没有标题的行跟随其后第一个声明者的层级
  （于是 `<p>` 写成的章题永远不会成为写了 `<h1>` 的行的父项），书自己画了树就一律照办（FR-012 / ADR-020）。
  仍不看排版字号与缩进：EPUB 2 参考书的节首全是 `<p>`，它照样是平铺的一列

- 拖拽平移**没有惯性**：松手即停，不做「甩一下滑一段」（连续列里加动量动画要与重排耦合，v1 不做）
- 中文的「一个词」是**指针所在的分句**，不是词典意义上的词：Qt 没有中文分词，而「双击取整段」与「双击取一个字」都不是读者想要的，
  所以按标点把 Qt 的整串收窄——代价是数字里的小数点也会切断（`3.14` 会分成 `3` 与 `14`），而西文完全交给 Qt（`don't`、`well-known` 原样）
- 选区只在**当前这一节**里有效：换章、关书或换书都会放下标记（位置属于那个文档），剪贴板里已经复制的内容不受影响

详见 `arch/architecture.md` 第 2.2 节与 ADR-001 / ADR-016 / ADR-020 / ADR-021 / ADR-022 / ADR-023。

|---|---|
| 单节排版（22,000 字，稳态）中位数 | **14.7 ms** |
| 窗口光栅化中位数（原型期记作「单页」） | **8.1 ms** |
| 避头尾违法行首 | **645 行 → 0** |
